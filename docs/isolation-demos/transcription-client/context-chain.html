FIXTURE MODE (mock Groq)

Each snip is one Groq Whisper call (the assembled speech segment, not a raw 4s chunk). With context, snip N gets a prompt: vocabulary first, then the tail of the transcript so far (about 150 words / 224 tokens). Snip N waits until N−1 resolves. That is slower than parallel calls; it keeps spelling and words split at a cut consistent.

Fixture mock is the safe default. Live Groq uses the same silent fixture blob for each snip so you can inspect prompts without a session zip.
